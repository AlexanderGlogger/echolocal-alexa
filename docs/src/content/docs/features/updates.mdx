## From Home Assistant

New versions show up under **Settings → Updates** through the device's **Firmware** entity.
Install from there, or press **Check for updates** to look now.

This is the only way on the Echo Dot.

## From the screen

On the Echo Shows,
**Settings → System → Software update** shows the current version, **Check for updates**, and
**Download and install** when an update is available.

## Checks

A few minutes after start, then daily. **Update status** shows what it's doing, and **Update
outcome** fires when an update finishes or fails.

## Update channel

**Update channel** (`update_channel`), on the screen or in Home Assistant:

- **Stable** (`stable`): releases
- **Development** (`dev`): the latest builds, for trying fixes early

Only newer builds are offered.
